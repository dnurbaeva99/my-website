# 🎨 Портфолио Сайт

Современное одностраничное портфолио с красивым дизайном и адаптивностью для всех устройств.

## ✨ Особенности

- ✅ **Адаптивный дизайн** - работает на всех устройствах (мобильные, планшеты, десктопы)
- ✅ **Современный стиль** - градиенты, анимации и эффекты наведения
- ✅ **Плавная навигация** - гладкая прокрутка между секциями
- ✅ **Форма контактов** - возможность отправить сообщение
- ✅ **Быстрая загрузка** - оптимизированный HTML, CSS и JavaScript
- ✅ **SEO-оптимизация** - правильная структура для поисковых систем
- ✅ **Социальные сети** - ссылки на ваши аккаунты

## 🛠️ Структура HTML

Сайт состоит из следующих секций:

1. **Навигация** - верхняя панель с меню
2. **Hero** - главная секция с приветствием
3. **About** - информация о вас и ваши навыки
4. **Projects** - портфолио ваших проектов
5. **Contact** - форма обратной связи и контактная информация
6. **Footer** - нижний колонтитул

## 🎨 Дизайн и цвета

```css

    --secondary-color: #8b5cf6;
    /* ... остальные цвета ... */
}
```

## 🔧 Как использовать

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/my-website.git
cd my-website
```

### 2. Открытие в браузере

Просто откройте файл `index.html` в вашем браузере.

### 3. Редактирование

Отредактируйте следующие файлы для персонализации:

#### **index.html**
- Измените "Ваше Имя" на ваше имя
- Обновите информацию в секции About
- Добавьте или удалите проекты
- Измените контактные данные

#### **styles.css**
- Измените цвета в переменных `:root`
- Отредактируйте шрифты и размеры
- Добавьте собственные стили

#### **script.js**
- Добавьте дополнительную функциональность
- Интегрируйте с API для отправки писем
- Добавьте анимации

### 4. Локальный сервер (опционально)

Для лучшего опыта разработки, используйте локальный сервер:

```bash
# С Python 3
python -m http.server 8000

# Или с Node.js
npx http-server
```

Затем откройте `http://localhost:8000` в браузере.

## 📝 Как персонализировать сайт

### Измените информацию о себе

1. Откройте `index.html`
2. Найдите секцию Hero и обновите текст
3. Обновите информацию в секции About
4. Добавьте или отредактируйте проекты

### Добавьте свои проекты

Найдите секцию "Мои проекты" в `index.html` и добавьте новую карточку:

```html
<div class="project-card">
    <div class="project-image">
        <i class="fas fa-icon-name"></i>
    </div>
    <h3>Название проекта</h3>
    <p>Описание вашего проекта...</p>
    <div class="project-tags">
        <span>Технология 1</span>
        <span>Технология 2</span>
    </div>
    <a href="#" class="project-link">Посмотреть проект →</a>
</div>
```

### Обновите контактную информацию

В секции Contact замените:
- Email: `your@email.com`
- Телефон: `+7 (999) 999-99-99`
- Местоположение: `Ваш город, Страна`

### Добавьте иконки Font Awesome

Сайт использует [Font Awesome 6](https://fontawesome.com/icons). Вы можете использовать любые иконки:

```html
<i class="fas fa-icon-name"></i>  <!-- Solid icons -->
<i class="fab fa-icon-name"></i>  <!-- Brand icons -->
```

## 🚀 Развёртывание на GitHub Pages

### 1. Убедитесь, что репозиторий публичный (Public)

### 2. Перейдите в Settings репозитория

### 3. Выберите вкладку "Pages"

### 4. Выберите ветку `main` и папку `/root`

### 5. Нажмите "Save"

Через пару минут ваш сайт будет доступен по ссылке:
```
https://USERNAME.github.io/my-website
```
